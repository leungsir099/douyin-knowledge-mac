# Douyin Knowledge

This is a local Markdown knowledge base generated from your saved Douyin videos.

- `Inbox/`: newly generated notes waiting for your review.
- `Knowledge/`: notes you decided to keep and organize.
- `Sources/`: optional indexes and source-oriented notes.
- `Creators/`: creator-level distillations and traceable per-video analyses.
- `Attachments/`: optional local attachments you add yourself.

Original media and full transcripts stay in the workflow state directory, not in this knowledge base.
